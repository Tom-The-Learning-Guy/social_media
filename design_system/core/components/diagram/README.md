# Diagram Components Boundary

This directory is reserved for reusable diagramming primitives (e.g. Node, Connector, ComparisonFlow) supporting Section 12 ("Animated Learning") of the Social Video Content Specification.

In Grain 1, structural components are kept to the minimal cross-profile foundation (SceneFrame, Stage, Statement, Annotation, EvidenceFrame). Diagram components will be implemented when animated explanatory flows are integrated in future grains.
