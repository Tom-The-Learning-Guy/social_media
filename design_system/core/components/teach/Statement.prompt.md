# Statement Component Guidance

The primary typography primitive for core claims, theses, definitions, and punchlines in 9:16 vertical video.

## Usage

```jsx
<Statement
  eyebrow="DISTINCTION"
  heading="I LIKE IT does not mean IT IS GOOD"
  accent="does not mean"
  subhead="Just because you like something doesn't make it good. Broccoli doesn't give a shit about your opinion."
  tone="accent"
  size="lg"
/>
```

## Sizes
- `xl`: Massive hook moments (96px headline).
- `lg`: Standard scene claim (72px headline).
- `md`: Evidence header or secondary concept (52px headline).
