# Pattern: Evidence Stack (Editorial Grunge)

- **ID**: `evidence_stack`
- **Profile**: `editorial_grunge`
- **Purpose**: Sequentially accumulates multiple documentary sources (headlines, filings, reports) to demonstrate an undeniable systemic pattern before resolving.

## Motion & Sequence
- State 0: First primary source lands (`REVEAL`, `--hold-inspect`).
- State 1: Second source stacks underneath while first recedes (`DEEMPHASIZE` + `REVEAL`).
- State 2: Third source lands; pattern is formally resolved (`RESOLVE`).
